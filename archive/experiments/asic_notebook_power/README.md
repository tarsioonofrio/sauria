# Archived SAURIA ASIC profiles

The `int16_4x4` and `int16_5x5` profile directories are retained here as the
configuration sources used by previous campaigns. Their historical synthesis,
simulation, and power summaries remain in
`experiments/asic_notebook_power/reports/` with their original run IDs and
commits. Use the active `experiments/asic_notebook_power/int16_4x5` profile
for the rectangular 20-multiplier configuration.
